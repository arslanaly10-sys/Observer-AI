# design-md

Each folder holds a `DESIGN.md` describing one brand's visual language. To apply one, read
`<brand>/DESIGN.md` and map its tokens into the project's Tailwind theme (`app/globals.css`).

**Observer AI uses `apple/DESIGN.md`** as its base, adapted for a premium Gulf real-estate product
(warm sand neutrals, a deep ink canvas and a single gold-leaf accent in place of Action Blue where noted in `DESIGN.md` at the repo root).

Source: https://github.com/VoltAgent/awesome-design-md (design-md/).
